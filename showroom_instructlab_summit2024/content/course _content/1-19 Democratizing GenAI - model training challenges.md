# 9 Simple steps to train an LLM wit InstructLab


1. Identify the gap in knowledge/skills
2. Collate data
3. Create qna.yamal fine
4. Create the attribution file
---
5. run a **taxonomy diff** to check for new information in the InstructLab Taxonomy
6. run **ilab generate** to create SDG
7. run **ilb train** to train your model 
7. run **ilab test** to run a smoke test
8. run **ilab convert** to create a new GGUF file
---
9. Serve your new model and chat with the new knowledge and skills
